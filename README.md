# VORTIX – Sistema Integral de Gestión de Soporte Técnico

VORTIX es una plataforma web diseñada para centralizar, organizar y optimizar los procesos de soporte técnico dentro de una organización, mediante la gestión de solicitudes a través de un sistema de tickets.

El sistema permite registrar incidentes, asignar técnicos responsables, realizar seguimiento a las solicitudes y administrar los procesos de atención desde una interfaz intuitiva y moderna.

## Funcionalidades principales

- Autenticación de usuarios mediante Supabase Auth.
- Gestión de usuarios y roles.
- Panel de Super Administrador.
- Panel de Administrador.
- Panel de Técnico.
- Panel de Usuario.
- Creación y administración de tickets.
- Asignación de solicitudes a técnicos.
- Clasificación de tickets por categorías.
- Seguimiento e historial de solicitudes.
- Gestión de notificaciones.
- Paneles estadísticos y reportes de soporte.

## Roles del sistema

- **Super Administrador:** administración y supervisión global de la plataforma.
- **Administrador:** gestión de usuarios, técnicos, categorías y tickets.
- **Técnico:** atención, actualización y resolución de solicitudes asignadas.
- **Usuario:** creación de tickets y consulta del estado de sus solicitudes.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Supabase
- PostgreSQL
- Git y GitHub

## Objetivo del proyecto

Desarrollar una solución tecnológica que permita mejorar la organización, trazabilidad y eficiencia de los procesos de soporte técnico, centralizando la información y facilitando la comunicación entre usuarios, técnicos y administradores.
